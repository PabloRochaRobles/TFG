# Detección de jugadas en partidas de ajedrez

## Instrucciones


1. Instala las dependencias y organiza las carpetas ejecutando:

```````````````````
python src/setup.py
```````````````````

2. En la carpeta 'Videos' se encuentran los vídeos de test. Si se quiere probar con otro vídeo se debe colocar ahí.


3. Ejecuta el programa principal para analizar los vídeos:

``````````````````
python src/main.py
``````````````````


4. Los resultados se guardarán en la carpeta 'output'.
